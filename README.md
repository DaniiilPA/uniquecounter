# Unique Logger (ExileApi Plugin)

Плагин для [ExileApi](https://github.com/exApiTools/ExileApi-Compiled), предназначенный для сбора уникальных предметов с текущей карты и выводящий статистику через кастомный HUD.

Работает в связке с аналитическим сервером: **[PoE Uniques Analytics API](https://github.com/DaniiilPA/Unique-Tracker)**.

> **Note:** Данный код полностью сгенерирован с помощью ИИ (AI Generated).

---

## Что делает плагин

* **Трекинг уников:** Сканирует предметы на земле, распознает неопознанные уникальные предметы по путям к текстурам (через базу [RePoE](https://repoe-fork.github.io/uniques.json)).
* **Отправка данных:** Раз в 5 секунд отправляет собранный батч уников на указанный сервер.
* **Отрисовка HUD:** Каждые 3 секунды запрашивает общую статистику (T0/T1 уники) с сервера и отображает её на экране поверх игры.

---

## Установка и использование

Плагин устанавливается стандартным способом для ExileApi:

1. Склонируйте или скачайте репозиторий в папку `Plugins/Source/UniqueLogger` вашего скомпилированного ExileApi.
2. Запустите ExileApi (плагин скомпилируется автоматически).
3. В настройках плагина внутри игры укажите:
   * `ServerEndpoint`: URL вашего сервера (например, `http://127.0.0.1:8000/api/drops`)
   * `ApiKey`: ваш `X-API-Key` ключ от сервера
   * `StatsEndpoint`: URL для получения статистики (например, `http://127.0.0.1:8000/api/stats`)
   * `StatsApiKey`: ваш `X-API-Key` ключ для статистики
