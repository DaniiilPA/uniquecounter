# Unique Logger (ExileApi Plugin)

Плагин для [ExileApi](https://github.com/exApiTools/ExileApi-Compiled)[cite: 13, 14], предназначенный для сбора уникальных предметов с текущей карты и выводящий статистику через кастомный HUD[cite: 14].

Работает в связке с аналитическим сервером: **[PoE Uniques Analytics API](https://github.com/DaniiilPA/Unique-Tracker)**[cite: 14].

> **Note:** Данный код полностью сгенерирован с помощью ИИ (AI Generated).

---

## Что делает плагин

* **Трекинг уников:** Сканирует предметы на земле, распознает неопознанные уникальные предметы по путям к текстурам (через базу [RePoE](https://repoe-fork.github.io/uniques.json))[cite: 14].
* **Отправка данных:** Раз в 5 секунд отправляет собранный батч уников на указанный сервер[cite: 14].
* **Отрисовка HUD:** Каждые 3 секунды запрашивает общую статистику (T0/T1 уники) с сервера и отображает её на экране поверх игры[cite: 14].

---

## Установка и использование

Плагин устанавливается стандартным способом для ExileApi:

1. Склонируйте или скачайте репозиторий в папку `Plugins/Source/UniqueLogger` вашего скомпилированного ExileApi[cite: 13, 14].
2. Запустите ExileApi (плагин скомпилируется автоматически)[cite: 13, 14].
3. В настройках плагина внутри игры укажите:
   * `ServerEndpoint`: URL вашего сервера (например, `http://127.0.0.1:8000/api/drops`)[cite: 14]
   * `ApiKey`: ваш `X-API-Key` ключ от сервера[cite: 14]
   * `StatsEndpoint`: URL для получения статистики (например, `http://127.0.0.1:8000/api/stats`)[cite: 14]
   * `StatsApiKey`: ваш `X-API-Key` ключ для статистики[cite: 14]
